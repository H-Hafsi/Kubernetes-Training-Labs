# Évaluations Kubernetes (k3s)

Ces questionnaires à choix multiples (QCM) permettent de valider les acquis des **Parties 1 et 2** du cours.

| Évaluation | Questions | Difficulté | Lien |
|------------|-----------|------------|------|
| **Partie 1 – Fondations** | 20 | Facile → Difficile | [Commencer](partie-1-fondations.md) |
| **Partie 2 – Configuration / Sécurité** | 20 | Facile → Difficile | [Commencer](partie-2-configuration-securite.md) |

!!! info "Fonctionnement"
    - Une seule réponse correcte par question.
    - Le score s’affiche en temps réel (ex. **14 / 20**).
    - Les bonnes réponses sont surlignées en **vert**, les mauvaises en **rouge**.
    - Une explication s’affiche après chaque réponse.
    - Les réponses sont sauvegardées localement dans le navigateur.

!!! tip "Conseil"
    Faites d’abord la Partie 1, puis la Partie 2.  
    Vous pouvez recommencer autant de fois que vous le souhaitez (bouton Reset du plugin).
